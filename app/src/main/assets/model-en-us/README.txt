This folder must contain the Vosk small English model's contents. It is
NOT included here (it's ~40MB and downloaded directly, no account needed)
and cannot be generated by an AI assistant — it's a real trained model.

1. Download (no signup, just a direct download):
   https://alphacephei.com/vosk/models
   -> "vosk-model-small-en-us-0.15" (~40MB zip)

2. Unzip it. You'll get a folder named something like
   "vosk-model-small-en-us-0.15" containing subfolders: am/, conf/, graph/,
   ivector/, README, etc.

3. Copy the CONTENTS of that folder (not the folder itself) directly into
   this directory, so you end up with:
     app/src/main/assets/model-en-us/am/
     app/src/main/assets/model-en-us/conf/
     app/src/main/assets/model-en-us/graph/
     app/src/main/assets/model-en-us/ivector/
     ...etc

4. Delete this README.txt (or leave it, it won't break anything — Vosk only
   looks for its own expected subfolders).

WakeWordListener.kt reads this exact asset folder name ("model-en-us") by
default via Vosk's StorageService.unpack().

Note: bundling this model adds ~40MB to your APK size. This is the
tradeoff for a fully offline, account-free wake word engine.
